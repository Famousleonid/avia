# AVIA: общие инструкции для агентов

Перед работой обязательно прочитай и соблюдай [.agents/rules/project.md](.agents/rules/project.md): это полный набор обязательных проектных правил, включая безопасность production, диагностику, UI и импорт.

Каталог правил, навыков и порядок совместного пополнения: [.agents/README.md](.agents/README.md). При выборе навыка читай его актуальную версию из `.agents/skills/` этого репозитория; личные копии AVIA-навыков могут устареть.

- Для сканированных FIG/IPL PDF и стандартного XLS/XLSX используй `.agents/skills/avia-import-manual-package/SKILL.md`.
- Для шаблонов Traveler из XLS/XLSX используй `.agents/skills/avia-traveler-workbook/SKILL.md`.
- Для Quantum сначала читай `quantum/README.md` и относящиеся к задаче материалы.
- Подтверждённые повторно используемые знания пополняй в соответствующем общем правиле, навыке или базе Quantum в рамках той же задачи. Исправляй первоисточник, не создавай противоречащие копии. Обновляй каталог при добавлении навыков.
- Не сохраняй в Git пароли, ключи, токены, `.env`, сессии и приватные исходные документы. Доступ на другом рабочем месте настраивается отдельно.
