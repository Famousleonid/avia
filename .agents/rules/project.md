При новом открытии Send Message очищать выбранные группы, чтобы Reply одному человеку не включал предыдущую рассылку. Высота Send Message ограничена viewport через modal-content/body, списки прокручиваются; AI скрыт на время этого окна, иначе его z-index5000 перекрывает Send на телефоне. Проверять серверные права и отсутствие controls для Technician/Team Leader, доступ Manager/Admin, обычную отправку и получение всеми ролями; браузерные отправки перехватывать.
